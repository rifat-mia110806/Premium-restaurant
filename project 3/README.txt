ROYALBITE — PREMIUM RESTAURANT WEBSITE
=========================================

FILES
-----
index.html  -> Website structure/content
style.css   -> Complete styling and responsive design

HOW TO RUN
----------
1. Extract the ZIP file.
2. Open the "royalbite-premium" folder.
3. Double-click index.html.
4. The website will open in your browser.

IMPORTANT
---------
The design is built with plain HTML and CSS.
No build tools, npm, Node.js, or framework are required.

The website uses remote Unsplash images and Google Fonts,
so an internet connection is required for the images/fonts
to load.

CUSTOMIZATION
-------------
Change restaurant name:
Search "RoyalBite" in index.html.

Change prices:
Search for "$" values in index.html.

Change images:
Replace the image URLs in index.html.

Change colors:
Open style.css and edit the variables near the top:

--gold
--gold-light
--black
--white

All visible website text is in English.
