ROYALBITE — PREMIUM RESTAURANT WEBSITE
=======================================

PROJECT OVERVIEW
----------------
RoyalBite is a premium restaurant website concept designed with
a modern, elegant and luxurious visual identity.

The project focuses on clean layout, strong typography,
immersive imagery and a responsive user experience across
desktop, tablet and mobile devices.

FILES
-----
index.html  -> Website structure and content
style.css   -> Complete styling, layout and responsive design

HOW TO RUN
----------
1. Extract the ZIP file.
2. Open the "royalbite-premium" folder.
3. Open "index.html" in any modern web browser.
4. The website will load directly without any installation.

TECHNOLOGY
----------
HTML5
CSS3
Responsive Web Design

No build tools, npm, Node.js or external framework are required.

IMAGES & FONTS
--------------
The website uses remote Unsplash images and Google Fonts.
An active internet connection is required for these external
resources to load correctly.

CUSTOMIZATION
-------------
Restaurant Name:
Search for "RoyalBite" in index.html and replace it
with your preferred restaurant name.

Prices:
Search for the "$" values in index.html.

Images:
Replace the image URLs inside index.html.

Colors:
Open style.css and edit the variables near the top:

--gold
--gold-light
--black
--white

RESPONSIVE DESIGN
-----------------
The website is designed to adapt to different screen sizes,
including desktop, tablet and mobile devices.

PROJECT STATUS
--------------
